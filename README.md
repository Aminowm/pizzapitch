# Барлаушы — робот-разведчик газа

**Робот заходит первым. Человек — только когда безопасно.**
**Робот бірінші кіреді. Адам — тек қауіпсіз болғанда.**

Автономный ровер заезжает в канализационный колодец, коллектор, теплотрассу или подземную выработку раньше человека. Он меряет метан, угарный газ, канализационные газы и пропан и передаёт данные по LoRa на базу бригадира. Дальше данные идут в ноутбук по USB и на сайт через хотспот телефона. Если газ опасный, робот останавливается, включает сирену, отъезжает назад и ждёт решения человека.

Проект для **Pizza Pitch** (Ulytau Hub, Жезказган, 14 ноября 2026). Команда: Саян, Әмір, Әліби.

## Как идут данные

1. Датчики MQ-4, MQ-7, MQ-135, MQ-2 → Arduino Mega (A0–A3)
2. Mega → LilyGO на ровере (UART, через делитель 5 → 3,3 В)
3. LoRa 433 МГц → LilyGO-база
4. База → ноутбук по USB (`dashboard/index.html`)
5. База → хотспот телефона «Barlaushy» → MQTT `broker.emqx.io`, канал `barlaushy/zhz1407`
6. Сайт подписан через WebSocket и обновляется в реальном времени

## Честно о прототипе

Датчики MQ недорогие, значения ppm оценочные, кислород они не измеряют. Прототип не является сертифицированным средством измерения. Промышленная версия: электрохимические сенсоры (O₂, H₂S, CO, CH₄), взрывозащищённый корпус, энкодеры, гусеницы, своё защищённое облако.
