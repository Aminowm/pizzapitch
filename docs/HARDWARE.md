# Барлаушы — робот-разведчик газа

Робот заезжает в коллектор, тоннель или подвал **раньше человека**, меряет газ по пути и передаёт по LoRa на ноутбук бригадира. При опасном уровне он останавливается, включает сирену, отъезжает назад и ждёт команды. На ноутбуке видны карта газа по метрам и вердикт «ВХОД РАЗРЕШЁН / ЗАПРЕЩЁН», а по кнопке печатается наряд-допуск.

```
firmware/rover_mega/rover_mega.ino   ← Arduino Mega на ровере (датчики, моторы, логика)
firmware/rover_lora/rover_lora.ino   ← LilyGO на ровере (мост Mega ↔ LoRa)
firmware/base_lora/base_lora.ino     ← LilyGO-база (LoRa → USB + Wi-Fi → MQTT → сайт)
dashboard/index.html                 ← локальный пульт по USB: Chrome/Edge, интернет не нужен
index.html, live.html, 3d.html       ← сайт (GitHub Pages): лендинг, живой пульт, 3D-модель
docs/DEPLOY_SITE.md                  ← как включить сайт и проверить поток данных
```

## 1. Что поставить в Arduino IDE

| Что | Где |
|---|---|
| Плата Mega | «Arduino Mega or Mega 2560» (есть из коробки) |
| Платы ESP32 | Менеджер плат → **esp32 by Espressif** → плата **TTGO LoRa32-OLED**, ревизия **V2.1 (1.6.1)** |
| Библиотеки | **LoRa** (Sandeep Mistry), **Adafruit SSD1306**, **Adafruit GFX**, **PubSubClient** (Nick O'Leary, только для базы) |
| Если LCD с I2C-платой | **LiquidCrystal_I2C** и `#define LCD_I2C 1` в rover_mega.ino |

**Частота LoRa:** посмотри наклейку на LilyGO (433 / 868 / 915). Если там не 433, поменяй `LORA_FREQ` **в обоих** скетчах LilyGO.
Если OLED на LilyGO не включается, поставь `#define BOARD_V2 0` (это старая ревизия V1.0).

## 2. Питание (самое важное — сделать первым)

```
 Li-ion 2S (7.4–8.4 В) ──┬──► L298N  «12V»  (моторы)
        │  выключатель   ├──► Mega   «VIN»  (её собственный стабилизатор)
        │                └──► LM2596 «IN+» ──► 5.0 В шина:
        │                                       MQ-4, MQ-7, MQ-135, MQ-2,
        │                                       серво, HC-SR04, LCD, буззер,
        │                                       LilyGO (пин 5V)
        └─ GND ──────── ОБЩИЙ для всего: батарея, L298N, Mega, LM2596, LilyGO
```

1. **Сначала мультиметр на батарею.** 7–8,4 В — всё правильно. 3,7–4,2 В — банки стоят параллельно, так L298N работать не будет, нужно переключить их последовательно.
2. **LM2596 настрой ДО подключения нагрузки:** подай батарею, крути винт потенциометра, пока на выходе не будет **5,0 В**. Если перепутать, можно сжечь все датчики.
3. На L298N перемычку «5V EN» оставь, но клемму **5V ни к чему не подключай** (иначе стабилизатор L298N будет бороться с LM2596).
4. Бюджет тока на 5-вольтовой шине: 4 датчика MQ ≈ 0,6 А, серво до 0,5 А на пиках, остальное ≈ 0,25 А. Итого ≈ 1,3 А, для LM2596 это нормально.

## 3. Подключение к Arduino Mega

| Модуль | Контакт модуля | Mega |
|---|---|---|
| **MQ-4** (метан) | AO | **A0** |
| **MQ-7** (CO) | AO | **A1** |
| **MQ-135** | AO | **A2** |
| **MQ-2** | AO | **A3** |
| все MQ | VCC / GND / DO | шина 5 В / GND / не подключать |
| **L298N** | ENA / IN1 / IN2 | **5** / **22** / **23** |
| | IN3 / IN4 / ENB | **24** / **25** / **6** |
| | **перемычки ENA и ENB снять!** | иначе нет регулировки скорости |
| | OUT1+OUT2 | 2 левых мотора параллельно |
| | OUT3+OUT4 | 2 правых мотора параллельно |
| **HC-SR04** | TRIG / ECHO | **30** / **31** (VCC — 5 В) |
| **Серво** | оранжевый / красный / коричневый | **9** / 5 В / GND |
| **Буззер** | + (или S) | **32** |
| **Кнопка** (необязательно) | одна нога / другая | **2** / GND |
| **LCD1602** (16 пинов) | VSS, RW, K | GND |
| | VDD, A | 5 В |
| | V0 | средняя ножка потенциометра (крайние — 5 В и GND) — это контраст |
| | RS, E | **40**, **41** |
| | D4, D5, D6, D7 | **42**, **43**, **44**, **45** |
| **LilyGO** (на ровере) | пин 5V / GND | шина 5 В / GND |
| | **GPIO 34** (приём) | ← Mega **TX1 (18)** **через делитель** |
| | **GPIO 13** (передача) | → Mega **RX1 (19)** напрямую |

**Делитель 5 В → 3,3 В из трёх резисторов по 10 кОм** (они есть у вас в пакетике):

```
Mega TX1 (18) ──[10k]──┬──► LilyGO GPIO 34
                       └──[10k]──[10k]── GND        (5 В × 20k/30k = 3,3 В)
```
Без делителя ESP32 на LilyGO можно сжечь.

Сервопривод на ровере поворачивает HC-SR04: «голова» смотрит влево и вправо, когда впереди препятствие.

## 4. Настройка за 15 минут (Mega, без LilyGO)

1. Залей `rover_mega.ino`, открой Монитор порта: **115200**, «Новая строка».
2. Подними ровер так, чтобы колёса висели в воздухе. Введи `RECAL` (пропустить прогрев), подожди 10 с, потом `MAN_F`.
   * Колёса крутятся назад → `INVERT_LEFT` / `INVERT_RIGHT = true`.
3. **Скорость:** временно поставь `MANUAL_PULSE_MS = 3000`, залей, поставь ровер на пол и введи `MAN_F` (3 с езды). Измерь путь рулеткой, раздели на 3 и запиши в `CM_PER_SEC_CRUISE`. Потом верни 500.
4. **Поворот:** `MAN_L`: если повернул меньше 90°, увеличь `TURN_90_MS`.
5. Медленная скорость `SPEED_SLOW = 140`: если моторы на ней пищат, но не едут, увеличь до 160.

Команды для Монитора порта: `START STOP RESUME RECAL BEEP MAN_F MAN_B MAN_L MAN_R`

## 5. Как работают датчики (и что говорить жюри)

* После включения идёт прогрев (`WARMUP_MS`, 2 мин), потом **10 с калибровки в чистом воздухе**: робот запоминает «ноль». **В это время не дыши на датчики и не подноси газ.**
* Опасность считается двумя способами, и берётся худший:
  1. насколько упало сопротивление датчика относительно чистого воздуха (35% = осторожно, 60% = опасно), это работает для всех четырёх;
  2. оценка ppm по кривой из даташита (для MQ-4 и MQ-7): метан 5000 ppm (10% НКПР) = осторожно, 10000 ppm (20% НКПР) = тревога; CO 25 / 50 ppm.
* Всё сводится к «индексу опасности», % от порога тревоги: 50 = жёлтый, 100 = красный.
* **Честно:** MQ-7 по даташиту требует циклического нагрева 5 В / 1,4 В. У нас нагрев постоянный, поэтому его показания — ориентир, а не точные ppm. MQ не измеряют кислород. Промышленная версия делается на электрохимических сенсорах и во взрывозащищённом корпусе.
* **Первичный прогрев (burn-in):** новые MQ стоит один раз продержать под 5 В **24–48 часов**. Начни прямо сегодня ночью: подай питание на датчики от LM2596 или от зарядки телефона.

## 6. LoRa и пульт

1. Залей `rover_lora.ino` в LilyGO на ровере и `base_lora.ino` в LilyGO-базу.
2. База по USB → ноутбук → открой `dashboard/index.html` в **Chrome или Edge** → «Подключить базу (USB)» → выбери COM-порт.
3. На OLED ровера должно появиться `Mega: OK` и растущий `TX #`, на OLED базы — RSSI в dBm.
4. Кнопки пульта: **СТАРТ**, **СТОП** (или пробел), **Продолжить** после тревоги, **Найти робота** (пищит), **Калибровка**, стрелки — ручное управление.
5. После миссии нажми «Наряд-допуск (PDF)» → в окне печати выбери «Сохранить как PDF».

**Сайт для судей:** база дополнительно подключается к хотспоту телефона (**Barlaushy / barlaushy2026**) и отправляет данные в MQTT-облако. Сайт https://aminowm.github.io/pizzapitch/ показывает их с любого телефона (только просмотр). Как включить сайт — в `docs/DEPLOY_SITE.md`.

**«Демо-режим»** — полная симуляция без железа (тоннель 10 м, газовый карман на ~6 м). Это **запасной план для сцены**, если что-то откажет.

Если страница не видит порт: закрой Монитор порта в Arduino IDE (порт может занимать только одна программа).

## 7. Демонстрация на сцене (безопасно)

* Тоннель: две коробки или картонные стенки длиной 1,5–2 м.
* Для короткой сцены поставь в прошивке `MISSION_MAX_CM = 200` и `STEP_CM = 25`.
* «Газовый карман»: в конце тоннеля пластиковый стакан, в который нажали газ зажигалки **без пламени**, один короткий пшик. MQ-2 и MQ-4 на бутан реагируют. Робот доезжает → сирена → отъезд → на пульте «ВХОД ЗАПРЕЩЁН».
* **Никакого огня рядом.** Угарный газ, сероводород и прочие токсичные газы не используем.
* Включи робота за **15+ минут** до выступления: прогрев, затем калибровка в зале подальше от стакана с газом.

## 8. План на 3 дня

| Когда | Что |
|---|---|
| **11.11 вечер** | Питание + настройка LM2596 на 5,0 В. Залить Mega, проверить моторы и датчики через Монитор порта. **На ночь оставить MQ под питанием (burn-in).** |
| **12.11** | Делитель + LilyGO ×2, проверить связь, подключить пульт. Калибровка скорости и поворота. Первая полная миссия на полу. |
| **13.11** | Картонный тоннель + тест с зажигалкой без пламени. **Снять видео удачного прогона** (запасной вариант). 3 репетиции питча. |
| **14.11** | Включить за 15 мин, откалибровать, на сцене — живая миссия; демо-режим и видео как запасные варианты. |

## 9. Если что-то не работает

| Симптом | Причина / что сделать |
|---|---|
| LCD светится, но пустой или одни квадраты | Покрути потенциометр контраста (V0) |
| Тревога сразу после калибровки | Калибровал в «грязном» воздухе или датчики не прогрелись → `RECAL` на свежем воздухе |
| Датчик всегда 0 | Проверь AO→A0..A3 и 5 В на VCC модуля |
| Робот крутится на месте | Одна сторона инвертирована → `INVERT_LEFT/RIGHT` |
| Робот всё время «объезжает» | HC-SR04 смотрит в пол или в корпус. Подними его; `OBSTACLE_CM` можно уменьшить до 20 |
| OLED ровера: `Mega: NET SVYAZI` | Перепутаны TX/RX или нет общего GND, проверь делитель |
| Пульт: «база подключена, ждём робота» | Разные `LORA_FREQ` / `LORA_SYNC`, не прикручены антенны (**никогда не включай LoRa без антенны**) |
| Mega перезагружается при старте моторов | Просадка питания: толще провода к батарее, конденсатор 470–1000 мкФ на вход L298N |
