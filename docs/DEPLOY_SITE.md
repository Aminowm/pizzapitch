# Как включить сайт на GitHub Pages (≈2 минуты)

Сайт: **https://aminowm.github.io/pizzapitch/**. На эту ссылку ведёт QR-код (`img/qr.png` и `img/qr_card.png`).

Файлы сайта уже лежат в корне репозитория (`index.html`, `live.html`, `3d.html`, `css/`, `js/`, `img/`).

## 1. Включить Pages


1. **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
3. Через 1–2 минуты сайт откроется по ссылке выше. Проверь три страницы:
   * `/` — лендинг с живой карточкой,
   * `/live.html` — полный пульт (только просмотр),
   * `/3d.html` — 3D-модель.

## 2. Проверить поток данных до питча

1. Прошей базу `firmware/base_lora/base_lora.ino` (нужна библиотека **PubSubClient**).
2. Назови хотспот телефона **Barlaushy**, пароль **barlaushy2026** (или впиши свои в начале скетча).
3. На OLED базы должно появиться `WiFi:OK Sait:OK`.
4. Включи ровер — на сайте появится значок **LIVE**.

Если ровера ещё нет под рукой: открой `live.html#demo` — это симуляция.

## Важно

* Брокер `broker.emqx.io` публичный и бесплатный. Сайт **только показывает** данные, управлять роботом с него нельзя. Но теоретически любой, кто узнает канал `barlaushy/zhz1407`, может туда что-то отправить. Для питча это нормально; для настоящего продукта нужен свой брокер с паролем (это есть на слайде «Сейчас → промышленная версия»).
* Если на месте нет интернета, сайт покажет «нет интернета», а локальный пульт `dashboard/index.html` по USB работает как раньше.
* Поменять канал: `TOPIC_ROOT` в `base_lora.ino` **и** `topicRoot` в `js/config.js`, одинаково.
